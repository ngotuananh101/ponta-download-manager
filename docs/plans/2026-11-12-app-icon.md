# Plan: new app icon — 2026-11-12

## Goal
Replace the app icon everywhere with the kawaii download-folder icon
the user sent (512x512 RGBA, transparent background).

## One-shot generation
The source is `apps/desktop/assets/images/icon.png` (the 512px file).
All derived icons are generated from it in one run by
`.muse-gen-icons.py` (kept out of the repo; the script is described
here so it can be re-run): PIL LANCZOS resizes for the PNGs,
ImageMagick `icon:auto-resize=16,32,48,256` for the multi-size .ico
files. Verified by sha256 of the source and by `magick identify` on
each .ico (4 frames) and PIL size checks on each PNG.

Generated files:
- `apps/desktop/assets/images/icon.ico` (16/32/48/256) — Windows tray
  icon, newly declared in pubspec assets. The tray code already
  referenced this path; the file did not exist before.
- `apps/desktop/windows/runner/resources/app_icon.ico` (16/32/48/256)
  — Windows exe icon, picked up at build time.
- `integrations/browser-extension/extension/icons/icon{16,32,48,128}.png`
  — extension icons; the manifest now declares `icons` and
  `action.default_icon` (it declared none before; only the
  notification iconUrl used icon48.png).

## Places that pick the icon up with no code change
- Linux: the bundled `assets/images/icon.png` is installed to
  `~/.local/share/icons/hicolor/256x256/apps/com.ponta.pdm.png` and
  referenced by the .desktop file (`Icon=com.ponta.pdm`), so the dash,
  dock, app switcher and tray follow it.
- Linux runner (`my_application.cc`) sets the window icon from the
  bundled asset; the AppHeader shows it at 16px via Image.asset.

## Code change: LinuxDesktopService installs the icon again on change
`_ensureIconInstalled` used to return early whenever an installed
icon file already existed, so an icon update never reached
`~/.local/share`. It now loads the bundled bytes, compares them with
the installed file and rewrites only when they differ. Test:
`test/core/services/linux_desktop_service_test.dart` (stale bytes are
replaced; identical bytes leave the file untouched).

## Verify
- Full desktop suite, `flutter analyze` clean,
  `flutter build linux --release`.
- Manual (user): rebuild/re-run the app; the dock, tray and header
  show the new icon. The installed hicolor icon updates on the next
  launch. Reload the extension in the browser to see its new toolbar
  icon. Windows .ico needs a Windows build to confirm visually.
